# siibra-tutorials

Tutorial notebooks for programmatic use of the [EBRAINS human brain atlas](https://ebrains.eu/service/human-brain-atlas) with [siibra-python](https://github.com/FZJ-INM1-BDA/siibra-python).
The notebooks are tested every week against the latest siibra release.

## Running the notebooks

- **[mybinder.org](https://mybinder.org)**: everything is installed, just run the cells.
- **Google Colab, EBRAINS Lab or your own Jupyter**: the first code cell of every notebook contains a
  commented-out `%pip install` line. Uncomment it and run it once. Alternatively, clone this repository
  and run `pip install -r requirements.txt`.

siibra downloads atlas data on demand, therefore, the first run of a notebook can take a while.
